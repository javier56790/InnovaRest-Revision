# InnovaRest

Versión funcional de revisión académica del proyecto InnovaRest.

## Requisitos

* Git
* Docker Desktop

## Ejecución

Clonar el repositorio:

```bash
git clone https://github.com/javier56790/InnovaRest-Revision.git
```

Entrar al proyecto:

```bash
cd InnovaRest-Revision
```

Ejecutar:

```bash
docker compose up --build
```

Abrir en el navegador:

```text
http://localhost:5173
```

## Credenciales

Las credenciales de los usuarios de prueba se encuentran en:

```text
credenciales.txt
```

## Base de datos

La base de datos de prueba se carga automáticamente desde:

```text
Database/innovarest.sql
```

## Detener la aplicación

```bash
docker compose down
```

> Esta versión corresponde a una entrega de revisión y puede recibir modificaciones posteriores.
